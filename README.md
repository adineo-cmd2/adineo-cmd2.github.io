# 🌌 Aditya Yadav — Personal Portfolio

A minimal, reflective, and deeply personal portfolio built with **React**, **Vite**, and a love for clean aesthetics.

> *“Create without pressure. Ship without apology.”*

---

## 📖 Overview

This repository contains the source code for my **personal portfolio website** — a digital home for my projects, writings, skills, experience, and personal journey.

Designed with intention, it blends **engineering discipline** with **personal expression**, reflecting my values around clarity, sustainability, and long-term growth.

### Built with

- **React** — Component-driven UI architecture
- **Vite** — Lightning-fast development & optimized builds
- **CSS-first styling** — Clean, minimal, and readable
- **Responsive & accessible** — Works beautifully on all screen sizes
- **Performance-focused** — Fast load times and minimal bloat

---

## 🎨 Design Philosophy

- **Monochrome depth**  
  Grayscale-heavy UI with subtle accents for focus

- **Intentional minimalism**  
  No unnecessary animations or distractions

- **Typographic honesty**  
  Readable fonts, balanced spacing, calm rhythm

- **No bloat**  
  Simple React components, no heavy UI libraries

- **Clarity over noise**  
  Every component serves a purpose

---

## 🛠️ Tech Stack Highlights

- **Framework:** React (Vite-powered)
- **Bundler:** Vite
- **Styling:** CSS (global + component-level)
- **State Management:** React props & structure (no overengineering)
- **Content Source:** Centralized static data (`src/data/content.js`)
- **Deployment:** Vercel / Netlify / GitHub Pages ready
